# Generic Website

A simple front-end project of a generic website, built using only **HTML5** and **CSS3**. The goal is to practice page navigation using the `<a>` tag in the menu and apply basic styling to visual elements.

## Features

- Navigation menu with (`<a>`) to switch between three pages.
- Display of generic products with a simple layout.
- Basic styling of blocks, text, and borders via CSS.

## Tech Stack

- **HTML5**
- **CSS3**

## Getting Started

1. Download or clone this repository.
2. Open the `index.html` file directly in your browser.
3. Use the links in the top menu to navigate between the pages.
